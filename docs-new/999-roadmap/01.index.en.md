# Feluqa roadmap

This page lists the framework work that is still in progress. It is not a promise of release dates.

## Workspace and crate architecture

The foundation is in place: Cargo workspace and lockfile at the repository root, existing framework crates grouped under `crates/`, build tooling under `tools/`, and product manifests updated to use the new paths. Rust is pinned through `rust-toolchain.toml`.

Remaining work: verify the declared MSRV and supported target lanes, add dependency-policy tooling, and align remaining package boundaries with the target map where a real implementation needs a split or merge. Implement bridges, runtime hosts and native shells only alongside a working contract and consumer. The [monorepo architecture](../technical/02.architecture/01.monorepo-architecture.en.md) shows the selected layout and labels the parts that are still targets.

## App developer experience

- Finish the shared UI component catalogue, themes and panel integration.
- Make generated apps build outside the repository checkout.
- Complete editor support and shared `.view.rs` compiler/editor conformance.

## Platform behavior

- Complete generic resource actions and Core workflows.
- Finish browser Live reconciliation and shared replay protection.
- Deliver dynamic module install, signatures, local licensing, upgrade and rollback.
- Qualify deployment, backup and restore.

## Local and cross-platform products

- Deliver a local workstation host with LAN clients and no Internet dependency.
- Define and implement offline writes, reconnect behavior and conflict handling.
- Complete desktop/mobile shells and their target-specific build lanes.
- Verify local identity, key custody, approvals, audit and package updates for disconnected installations.

## Compilation and reporting

- Measure build time and workstation resource use before changing crate boundaries.
- Implement deterministic generation and resource-aware build control.
- Deliver shared, authorized business dashboards without compiling user data.

See the [enterprise delivery plan](../technical/roadmap/02.enterprise-delivery.en.md), [crate migration plan](../technical/roadmap/08.crates-change-plan.en.md), and [compilation requirements](../technical/02.architecture/02.compilation-and-targets.en.md) for implementation detail.
