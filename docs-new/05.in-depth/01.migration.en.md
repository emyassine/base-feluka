# Migrate and upgrade

Migration work covers two separate areas:

1. **Application data:** SQL migrations are owned by modules and applied explicitly. Schema rollback does not restore deleted data.
2. **Framework layout:** the Cargo workspace now lives at the repository root, and existing framework packages are grouped under `crates/`. Bridges, runtimes and native shells remain future implementation work.

Do not combine these migrations. Follow [Working with Databases](../02.getting-started/11.working-with-databases.en.md) for app data and [the workspace roadmap](../999-roadmap/01.index.en.md) for framework changes.
