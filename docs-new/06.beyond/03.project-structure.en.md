# Project Structure

The architecture target groups reusable Rust crates by domain. Native OS shells live outside the Cargo workspace. Products and modules consume the framework through the `feluqa` facade.

```text
feluqa/
├── crates/       # core, macros, UI, bridges, services, platform, runtimes
├── shells/       # Apple, Android, GNOME, KDE, Windows, web
├── products/     # CLI, editor and app consumers
├── docs-new/     # developer-facing framework documentation
└── tools/        # workspace tooling and build support
```

The selected root Cargo workspace and domain-grouped framework crates are in place. Target bridge, runtime and shell packages are not present until they have useful code and a consumer. `docs-new/999-roadmap/` lists the user-facing work; the [Monorepo Architecture](../../docs/02.architecture/01.monorepo-architecture.en.md) contains the complete crate map.
