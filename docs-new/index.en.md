# Feluqa documentation

Feluqa is a server platform. Operators install it on a server; developers
create modules that run on it. This documentation separates **what Feluqa is
intended to do**, **what exists today**, and **what remains to build**.

Choose your audience:

- [For organizations](exists/for-organizations/index.en.md): understand the
  platform, domains, modules, licensing, data and current availability.
- [For module developers](exists/for-developers/index.en.md): build a module,
  add panels/resources, store data, authorize actions, write views and test.
- [Knowledge and product intent](knowledge/index.en.md)
- [Current implementation](exists/index.en.md)
- [Planned work](_todo/index.en.md)

Pages use `<slug>.<language>.md`. Translations share the same slug, for example
`platform-overview.en.md` and `platform-overview.fr.md`. The code is lowercase
and kebab-case; the language suffix is an ISO-style language code.

The repository [README](../README.md) is the quick start for the current
workspace. Product-specific implementation details are collected under
[product guides](exists/products/index.en.md); the platform documentation
does not repeat them.
