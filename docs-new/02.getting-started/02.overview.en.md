# Getting started

Build a web app inside this repository, run it with `feluqa dev`, and add your own module code. The CLI and local framework crates are under active development; the repository checkout is the supported starting point.

## Follow these steps

1. Install the Rust toolchain and required system libraries. See [Tooling Setup](03.tooling-setup.en.md).
2. Create an app with [the Feluqa CLI](04.creating-a-new-app.en.md).
3. Add a page using a [compiled view](05.your-first-component.en.md).
4. Add data and routes using the [database](11.working-with-databases.en.md) and [routing](12.routing-and-structure.en.md) guides.
5. Run [checks and tests](../04.guides/05.testing-and-debugging.en.md).

The current UI template language is `.view.rs`. It is not RSX. See [Creating UI with RSX](06.creating-ui-with-rsx.en.md) for the current limitation.
