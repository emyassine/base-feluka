# Style your app and add assets

Place public files under the app's configured `public/` directory. Feluqa serves those files as web assets. Do not put secrets or mutable application data in the public directory.

Keep styles and scripts in local assets so a disconnected installation does not depend on a remote content-delivery network. The panel crate also owns its framework assets; products should not copy those assets into their app.

The full theme API and component styling integration are not complete. See [the UI roadmap](../999-roadmap/01.index.en.md).
