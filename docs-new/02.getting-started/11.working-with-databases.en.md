# Work with databases

Feluqa currently supports SQLite and PostgreSQL through SeaORM. SQLite is the development default. Apps can configure named connections for external or legacy databases.

Each module owns its migration files. Provide matching migration identities for every dialect the app supports. Run migrations explicitly with `feluqa migrate`; seeders are separate from migrations.

```sh
feluqa make migration create_books
feluqa migrate
```

See [the database guide](../../docs/03.for-developers/06.data-and-migrations.en.md) for migration layout and recovery limits.
