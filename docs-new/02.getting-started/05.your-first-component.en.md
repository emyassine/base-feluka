# Your first component

Feluqa pages use compiled `.view.rs` templates. Start with semantic HTML, then use components registered by your app or panel.

```html
<section>
  <h1>Books</h1>
  <p>Manage the bookstore catalogue.</p>
</section>
```

Place the view in a declared view root and render it through the owning route or panel. The template compiler reports missing views and invalid Rust expressions during the build.

The shared component catalogue and theme integration are still incomplete. See [Building User Interfaces](../03.core-concepts/02.building-user-interfaces.en.md) and [the view guide](../technical/03.for-developers/04.views-and-components.en.md).
