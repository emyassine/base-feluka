# Add a backend

A Feluqa web app is a Rust application with server routes, services and data access. Keep handlers small: validate the request, authorize it, call a service and map the result to a response.

The current web profile uses Tokio, Axum and Tower. The target architecture keeps server dependencies out of shared kernel and `no_std` crates.

See [Fullstack](../03.core-concepts/04.fullstack.en.md) and the [web profile reference](../technical/02.architecture/07.web-profile.en.md).
