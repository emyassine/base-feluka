# Feluqa at a glance

Feluqa is a Rust framework for building web products and business modules. It provides a shared application model, CLI, data and authorization foundations, compiled views, and a panel catalogue.

A Feluqa product combines the platform with one or more modules. A module owns its business rules. The platform provides the runtime and shared services.

## What works now

This repository has a working web application foundation: the `feluqa` facade, a CLI, a build-time `.view.rs` compiler, SQLite and PostgreSQL support, authentication and authorization foundations, and statically composed modules.

## Where Feluqa is going

The architecture supports one product model across hosted web and local deployments. A local Feluqa host should serve nearby devices without Internet access. Desktop, mobile, dynamic module installation, offline synchronization and production deployment still need implementation.
