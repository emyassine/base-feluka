# Test and debug

Run checks from the repository root:

```sh
cargo fmt --all --check
cargo check --workspace --all-targets --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
```

For an app, run `feluqa check`, `feluqa test` or `feluqa dev` from its directory. Tests should exercise the public API as an application uses it. Security changes need denial-path tests, and view changes need compiler and rendering coverage.

Do not claim a check passed unless you ran it on the code being described.
