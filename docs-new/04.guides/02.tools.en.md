# Tools

The `feluqa` CLI provides `new`, `dev`, `build`, `check`, `test`, `migrate`, `seed` and `make` commands in the contexts where they apply.

From this checkout, inspect help with:

```sh
cargo run -p feluqa-cli -- help
```

For command behavior and generators, see [the CLI reference](../technical/05.reference/01.cli-commands.en.md). Zed tooling is available, but editor acceptance still needs work; see [Zed setup](../technical/05.reference/02.zed-editor.en.md).
