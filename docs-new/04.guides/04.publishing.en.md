# Publish your app or module

Feluqa and its crates are proprietary. The repository uses a private registry. Do not publish crates, modules or editor extensions publicly without an explicit owner decision.

Dynamic module packaging, signing, registry installation, licensing and rollback are target capabilities. Today, app modules are statically linked into a compiled product.

See [the proprietary distribution policy](../../docs/06.governance-and-policy/02.proprietary.en.md).
