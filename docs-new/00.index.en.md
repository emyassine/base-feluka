# Feluqa documentation

Feluqa is a Rust framework for building web applications and installable business modules. These guides explain how to use the framework and what works in this checkout.

This is the main documentation index. Start with the guides below. The links in **Technical reference** lead to deeper architecture, implementation and policy documents kept in `technical/`; they are part of the same documentation set.
