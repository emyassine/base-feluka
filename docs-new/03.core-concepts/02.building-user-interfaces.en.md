# Build user interfaces

Feluqa separates UI meaning from rendering. The target architecture uses a shared Rust UI core and renderers or shells for each platform.

In the current web app, pages use compiled `.view.rs` templates. The component catalogue exists but its themes and full panel integration are unfinished. Native shells and RSX are not shipped authoring paths.

See [the view language](../../docs/05.reference/05.view-language.en.md) and [the UI architecture](../../docs/02.architecture/05.feluqa-ui-headless-and-shells.en.md).
