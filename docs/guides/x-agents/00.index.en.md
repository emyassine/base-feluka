# AI Agent Skills

This guide collects reusable skills for AI agents working on Feluqa. Each
skill describes a focused workflow for a recurring task, such as inspecting a
crate, changing documentation, or validating a subsystem.

Skills supplement the repository's `AGENTS.md` and the relevant product or
technical guides. They do not override those instructions, change the
implementation status of a feature, or replace the repository's normal review
and validation requirements.

## Documentation for the published site

Write documentation as standalone site content, independent of the monorepo.
Do not link to repository files using relative paths such as
`../../../../LICENSE`; refer instead to files distributed with source code or
to product resources, and describe unavailable resources as planned.

## Available skills

No Feluqa-specific skills are published here yet. Add a skill when a task has
a repeatable workflow that benefits from dedicated instructions; keep general
repository rules in `AGENTS.md` and link to them instead of copying them into
every skill.
