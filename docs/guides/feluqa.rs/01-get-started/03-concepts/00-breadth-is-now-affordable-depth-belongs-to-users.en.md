# Breadth Is Now Affordable; Depth Belongs to Users

We believe modern development tools make broad platform capabilities more
attainable for a small team. A coherent platform can provide shared SDKs,
development tools, schemas, and target runtimes across many kinds of
applications.

No platform team can anticipate every organization's specialized workflows.
Users and their agents can shape that domain-specific depth by building
Modules for their own needs. Feluqa aims to provide the breadth; its users
decide which specialized capabilities to build on top of it.

This is a product belief and direction, not a claim that every target runtime
or platform capability is already delivered. The goal is to measure progress
by how quickly a person or agent can take a domain need to a running
application, rather than by counting framework features.
