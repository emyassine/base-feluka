# Feluqa documentation (English)

This structure is stable across major documentation versions. Each major
version gets its own guide root and begins with the prologue, then the welcome
guide and technical topics.

Naming: `[order]-folder/[order]-file.en.md`.

1. Start with [`000-prologue/010-release-notes.en.md`](000-prologue/010-release-notes.en.md)
   for versioning and release information.
2. Read [`000-prologue/020-licence.en.md`](000-prologue/020-licence.en.md) for
   ownership and contributor terms.
3. Read the [`000-prologue/030-contribution-guide.en.md`](000-prologue/030-contribution-guide.en.md)
   before contributing. The Upgrade Guide is added when there is an earlier
   major version to upgrade from.
4. Explore [Components](000-prologue/040-batteries-included.en.md)
   capabilities and their current status.
5. Read about the [complementary agent project](../x-agents/get-started/agentic-development/complementary-agent-project)
   and its intended relationship with Feluqa.
6. Begin learning Feluqa at
   [`010-get-started/000-introduction/010-introduction.en.md`](010-get-started/000-introduction/010-introduction.en.md),
   then continue through the product model, taxonomy, architecture overview,
   and the [learning guides](010-get-started/060-learning/010-create-your-first-application.en.md).

Contributors to Feluqa itself can start with the
[Core Contribution guide](../internals/get-started/010-overview/010-internals-overview.en.md).

AI-agent skills are maintained separately in [`../x-agents/get-started/overview/agents-overview`](../x-agents/get-started/overview/agents-overview)
and are introduced by the Contribution Guide.
