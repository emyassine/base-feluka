Mainline design source
======================

The Hero, Logos, Features, Resource Allocation, Testimonials, Pricing, FAQ,
and Footer sections in the Vue blocks in this directory are ports of the
Mainline Next.js template by shadcnblocks.com. The home page uses the source
template's sample copy and visual assets as requested. Component data is
provided directly as Vue props from `docs/guides/index.en.md`.

Images under `assets/` are copied from the original template's `public/`
directory and remain visual placeholders from that template.

Source: https://github.com/shadcnblocks/mainline-nextjs-template
Template: https://www.shadcnblocks.com/template/mainline
