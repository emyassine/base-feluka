Voici la liste des bibliothèques standards de facto en Rust, classées par domaine :

⚙️ Sérialisation et Données

• serde : Le framework standard pour sérialiser et désérialiser les structures de données Rust de manière ultra-efficace.
• serde_json / toml / bincode : Les extensions de serde pour gérer des formats spécifiques (JSON, TOML, binaire).

🔄 Asynchronisme et Concurrence

• tokio : Le runtime asynchrone le plus populaire pour écrire des applications réseau fiables et rapides.
• futures : Fournit les extensions et utilitaires essentiels pour manipuler les Futures et les Streams.
• crossbeam : Outils de programmation concurrente à bas niveau (structures de données sans verrou, canaux avancés).
• rayon : Bibliothèque de parallélisme de données qui transforme vos itérateurs simples en itérateurs parallèles en une ligne (par_iter).

🛠️ Gestion des Erreurs

• anyhow : La solution standard pour la gestion des erreurs dans les applications (facilite le chaînage et l'affichage des erreurs).
• thiserror : L'outil standard pour concevoir des erreurs sur mesure dans les bibliothèques (dérive proprement le trait Error).

🌐 Réseau et Web

• reqwest : Le client HTTP standard (synchrone ou asynchrone) pour faire des requêtes web facilement.
• axum / actix-web : Les frameworks web dominants et ultra-performants pour bâtir des API et des serveurs HTTP.

🧮 Utilitaires Fondamentaux

• rand : La bibliothèque standard pour la génération de nombres aléatoires et le chiffrement de base.
• chrono / time : Les outils de référence pour manipuler les dates, les heures et les fuseaux horaires.
• regex : L'implémentation officielle et hautement optimisée des expressions régulières (garantie sans dépassement de temps linéaire).
• lazy_static / once_cell / lazy_cell : Utilisés pour l'initialisation paresseuse de variables globales ou statiques (Note : OnceCell est maintenant en partie dans std).

🖥️ Ligne de Commande (CLI)

• clap : Le gestionnaire d'arguments en ligne de commande de référence, extrêmement puissant et basé sur la dérivation de structures.
• log : Une API de façade d'enregistrement (logging) légère.
• tracing : Le framework moderne de l'écosystème Tokio pour collecter des métriques et du traçage structuré et asynchrone.


🗄️ Bases de données

• sqlx : Le toolkit SQL asynchrone standard pour manipuler PostgreSQL, MySQL ou SQLite avec une vérification des requêtes à la compilation (sans ORM).
• diesel : L'ORM synchrone historique et ultra-performant, garantissant une sécurité maximale des types pour vos requêtes.
• sea-orm : Un ORM asynchrone moderne bâti au-dessus de sqlx, idéal si vous préférez une approche dynamique style "Active Record".
• redis : Le client officiel et standard pour interagir avec les instances Redis.

🔐 Sécurité et Cryptographie

• ring : La référence absolue pour les primitives cryptographiques (crypto de base, signatures, hachage), basée sur du code BoringSSL hyper optimisé.
• rustls : L'alternative moderne, hautement sécurisée et entièrement écrite en Rust à OpenSSL pour la gestion des connexions TLS.
• jsonwebtoken : La bibliothèque standard pour générer et valider des tokens JWT.
• argon2 / bcrypt : Les caisses standards de l'organisation RustCrypto pour le hachage sécurisé des mots de passe.

🎮 Graphisme et Moteurs de Jeu

• bevy : Le moteur de jeu 2D/3D moderne basé sur une architecture ECS (Entity Component System) orientée données, devenu un standard absolu.
• wgpu : L'implémentation Rust portable et sécurisée des spécifications WebGPU, utilisée pour le rendu graphique bas niveau (Vulkan, Metal, DirectX).
• egui / iced : Les deux bibliothèques phares pour concevoir des interfaces graphiques (GUI) natives et légères, particulièrement adaptées aux outils et aux jeux.

🧱 Manipulation de formats de fichiers

• csv : Le parseur ultra-rapide et standard pour lire et écrire des fichiers CSV (s'intègre parfaitement avec serde).
• image : La bibliothèque de référence pour décoder, encoder et manipuler les formats d'images courants (PNG, JPEG, GIF, etc.) sans dépendances externes.
• quick-xml : Un parseur XML extrêmement rapide (lecture en continu / streaming) et économe en mémoire.

🛠️ Système et Bas Niveau

• bytes : Fournit des abstractions robustes (Bytes, BytesMut) pour manipuler des tampons de mémoire de manière très efficace, essentielle pour le réseau.
• nix : Les liaisons (bindings) Rust amicales et sécurisées pour les API des systèmes d'exploitation Unix/Linux (POSIX).
• memmap2 : La bibliothèque standard pour mapper des fichiers en mémoire (Memory-mapping), indispensable pour les hautes performances d'E/S.

🧪 Tests et Profilage

• criterion : Le framework de benchmark standard pour mesurer précisément les performances de votre code avec des statistiques détaillées.
• proptest : Outil standard pour faire du Property-based testing (génère des milliers d'entrées aléatoires pour trouver des cas limites).
• mockall : Le framework de création de doublons (mocking) le plus populaire pour simplifier l'écriture de tests unitaires complexes.
