# Products built with Feluqa

Feluqa is the foundation for products with their own audiences, workflows, and
identity. This catalog introduces the products built with Feluqa and links to
each product's own documentation.

Products can follow different distribution models. Some will be open source;
others will be proprietary. Each product's page will describe its purpose,
documentation, and applicable license or availability.

## Explore the products

### [Feluqa CLI](./010-feluqa-cli/index.en.md)

The developer and operator command line for creating and working with Feluqa
applications.

### [Nadim CLI](./020-nadim-cli/index.en.md)

A personal command-line product for focused everyday workflows, with its own
command profile in the current Feluqa console.
