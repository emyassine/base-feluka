# Prologue artwork

These Lucide SVGs illustrate the capability areas in the Batteries Included
guide. The icons are decorative; their adjacent headings carry the meaning.

| File | Guide area |
|---|---|
| `code-xml.svg` | Application foundation |
| `timer.svg` | Asynchronous server execution |
| `server-cog.svg` | Web and API services |
| `shield-check.svg` | Identity, access control, and audit |
| `database-zap.svg` | Data persistence |
| `blocks.svg` | Modules and extensibility |
| `panel-top.svg` | Panels and resources |
| `terminal.svg` | Console and developer CLI |
| `activity.svg` | Live interactions |
| `cloud-cog.svg` | Deployment and operations |
| `bot.svg` | Agent workflows |
