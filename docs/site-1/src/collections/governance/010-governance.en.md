# Governance and Stewardship

Numerimondes SARL AU stewards Feluqa's platform, product direction, and
proprietary components. Maintainers review engineering changes against the
documented architecture, security boundaries, and contribution terms.

Contributions are discussed before work is incorporated. Scope, access, and
applicable terms are agreed with the maintainers; the
[contribution guide](/prologue/contribution-guide) explains how to start.

Feluqa has not announced a release cadence, general support period, or
release-wide security response-time commitment. Release notes and applicable
product terms describe commitments when they are established. Do not infer a
service level from the repository structure or development status.

The project is proprietary today, while some individual components may be
released under open-source licences. Each component and release identifies its
applicable terms; see [Build with Feluqa](/prologue/licence) for the current
licensing model.
