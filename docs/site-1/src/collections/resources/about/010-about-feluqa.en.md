# About Feluqa

Feluqa is a proprietary platform and unified namespace for building
applications across web, workstation, mobile, games, APIs, and real-time
systems. It brings shared developer tools and contracts together while keeping
runtime profiles suited to each target.

The current repository provides selected framework foundations. The full
workspace, runtime shells, and dynamic module lifecycle described in the target
architecture are still under development.

Feluqa is created and stewarded by [Numerimondes SARL AU](/resources/about/who-is-behind-feluqa).
The [product catalog](/products/) introduces Feluqa CLI and Nadim CLI.
