# Privacy and Site Data

This notice applies to this documentation site. It is separate from any
Feluqa application that an organisation builds or operates.

## Data handled by the documentation site

The site does not require an account and has no visitor contact form. The
documentation frontend has no advertising or analytics tracker configured.
Search uses a MiniSearch index delivered with the site and runs in the
visitor's browser; search terms are not sent to Feluqa as analytics events.

The site does not use browsing activity to build visitor profiles or to send
marketing messages. Interface preferences may be stored by the browser for the
site experience; they are not submitted as visitor analytics by this site.

## Hosting and network delivery

Serving any website requires its hosting infrastructure to handle connection
data. Depending on the deployment, this can include an IP address, request
time, requested path, and browser information in operational or security logs.
The hosting provider and deployment configuration determine access and
retention for those logs; the documentation frontend does not set that policy.

Links to other services, including company and code-hosting sites, leave this
documentation site. Those services apply their own privacy practices.

## Products and contact

This notice does not cover a Feluqa application, CLI, or other product. Each
product operator is responsible for explaining its own data handling. To ask
about this site or Feluqa's privacy practices, contact
[Numerimondes](mailto:contact@numerimondes.com).
