# Feluqa platform: current baseline and target

Status reviewed from repository contracts and source on 2026-10-28. This page
separates implementation inventory from product ambition; no runtime tests were
rerun for the documentation migration.

Feluqa is a proprietary Rust platform and unified namespace for web, workstation,
mobile, games, APIs and real-time systems. Shared schemas and tooling support
separate runtime profiles. Web delivery is the first priority. One business module
serving hosted web and a standalone workstation is a target, not a delivered
cross-platform runtime.

## Current implementation inventory

| Area | Bounded status and evidence |
|---|---|
| Workspace | [Delivered] `_crates/Cargo.toml` and lockfile own Cargo; products remain under `products/`. Resolver 3, edition 2024, workspace MSRV declaration 1.85. Declared versions are not proof of MSRV builds. |
| Facade | [Delivered] `feluqa::...` facade with feature boundaries. `web` is currently the default feature; non-web consumers must disable defaults. A target feature name does not prove a complete runtime. |
| Definitions / Console | [Delivered] context and portable-path contracts, command metadata/discovery, synchronous dispatch and context filtering. Async Console and universal JSON output remain targets. |
| Views | [Delivered] build-time `.view.rs` compiler/runtime with typed escaping, URL validation and integration fixtures. Shared compiler/editor corpus and interactive Zed acceptance remain incomplete. |
| Auth / data / Core | [Delivered] authorization contracts, SeaORM SQLite/PostgreSQL pools and migrations, persistent identity/session/tenant/audit foundations. This is not a complete enterprise operations qualification. |
| Panel | [Delivered] generic catalogue. **The built-in System panel has been removed under D-0033.** Older `/system` guides and captures are historical and are not instructions for a supported current panel. |
| UI | Source packages and runtime forks exist. Complete compilation, product SSR/hydration, accessible components, themes and browser acceptance remain unfinished. Some UI packages declare Rust 1.88. Source ownership does not prove feature completion. |
| Live / modules | [Delivered] signed typed action foundation and static module ordering/rollback contracts. Shared replay, browser reconciliation and dynamic installable artifacts remain incomplete. |
| Product consumer | Numerimondes and CLI scaffolding contain transitional integration. Prior successful HTTP tests do not prove the current post-removal checkout builds. Compilation notes explicitly record application breakage. |

## Targets and limits

[Target] Installable modules, per-domain licensing, deploy/restore qualification,
resource-driven application generation, complete panels, production Live, BI and
web/workstation products require the acceptance work in the [roadmap](03.roadmap.en.md).
Desktop runtime, local storage topology, offline writes, synchronization and
conflict handling are not selected. OIDC, agent principals, MCP, native shells
and one-command deployment in the product proposal are not shipped capabilities.

[Exploring] Conflicting workspace, crate and native-shell proposals are recorded
in [pending decisions](../decisions/01.pending-decisions.en.md). Keep current
contracts until an owner decision explicitly changes them. In particular,
`feluqa-core` currently owns persistent identity services, not a no_std scheduler.
