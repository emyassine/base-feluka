# Planned changes to `_crates/`

[Target] This is an implementation plan, not an applied code migration. Source
and manifest inventory was inspected on 2026-10-28; runtime/build acceptance was
not rerun. Decisions DOC-* refer to [the pending register](../decisions/01.pending-decisions.en.md).
The existing workspace layout remains in place until DOC-01 is decided.

## Observed baseline

`_crates/Cargo.toml` has resolver 3, workspace version 0.2.0, edition 2024 and
MSRV 1.85; individual packages use their own versions, and several UI packages
declare 1.88. The facade enables `web` by default. Portable profiles require
`default-features = false`; feature names do not establish working native runtimes.
Current Core depends on database/auth/SeaORM/Tokio. Definitions exports contexts,
paths, products and remote links. UI source packages and local patches are present,
but the compilation document records unresolved application breakage.

## Conditional workspace move checklist

Only after DOC-01 approval: enumerate all member paths, path dependencies and
patches; update CLI workspace markers and watched directories in definitions and
products; rebase product manifests, scripts, package include paths and notices;
verify target output stays under repository `target/`; regenerate lockfile only
if required by actual dependency changes. Preserve package identities and private
registry restrictions unless separately approved. Validate external scaffolds
against an available approved registry release; local path builds are insufficient.

For DOC-03 UI renames, distinguish package rename, Rust import alias and public
facade stability. Produce an explicit old-to-new map before editing manifests;
carry provenance and license notices with source. Never move identity data or
rename persisted schemas as an incidental crate reorganization.

## Verification gates

Run scoped tests while implementing, then the repository's required checks:

```sh
cargo fmt --manifest-path _crates/Cargo.toml --all --check
cargo check --manifest-path _crates/Cargo.toml --workspace --all-targets --locked
cargo clippy --manifest-path _crates/Cargo.toml --workspace --all-targets --locked -- -D warnings
cargo test --manifest-path _crates/Cargo.toml --workspace --locked
```

Add declared MSRV and non-web/feature-specific builds, compiler negative cases,
filesystem containment/symlink tests, tenant/authorization denial and browser
acceptance where the work touches those boundaries. A newer compiler passing
cannot establish MSRV. Record toolchain, commands, results, remaining failures
and representative consumer for each work package; estimates follow the spike.

This documentation change updates only an existing dependency-policy link inside
`_crates/`; it does not modify Rust, Cargo configuration, lockfiles or runtime code.
