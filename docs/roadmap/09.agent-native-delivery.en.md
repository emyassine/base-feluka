# Agent-native delivery

[Target] The product proposal makes agents first-class users and builders. No
MCP service, agent identity subsystem or universal JSON mode is claimed delivered.
This plan preserves that ambition while making acceptance explicit.

| ID | Work / owner | Dependencies and acceptance |
|---|---|---|
| AN-01 | Versioned machine output in Console and CLI | Keep interactive/piped behavior; JSON schema, stable exit codes and stderr progress; golden contract cases for success, denial, cancellation and invalid input. Audit each command before claiming `--json` everywhere. |
| AN-02 | Generated capability catalogue in build tooling | F11/F12: deterministic modules/routes/permissions/config/error inventory derived from source, with schema versions and no credentials. Verify duplicate detection and no-op output. |
| AN-03 | Distinct agent principals in auth/Core | Implement distinct agent principals with scoped grants, tenant/record isolation, revocation and attributable audit, with denial coverage. The Product Document leaves approval defaults by domain tier open. |
| AN-04 | Tool/API surface, potentially MCP | Decide protocol/version and hosting boundary before adding a crate. Route tools through the same authorized services; validate input and bound work. Untrusted content remains data, never policy. |
| AN-05 | Verification and generated contributor instructions | Preserve human-readable diagnostics; generate optional project AGENTS.md from supported contracts. Evals cover task completion and denial, without granting agents publication or destructive permissions implicitly. |
| AN-06 | Deployment automation | F6/F7 and update policy: staged artifacts, compatibility, secrets handling, readiness, rollback and restore evidence. A JSON success message alone cannot prove deployment safety. |

No new empty service crate is required by this plan. Implement one real consumer
and one useful contract at a time. Approval policy and replay/revert semantics
remain explicit design work; audit records cannot undo arbitrary data mutations.
