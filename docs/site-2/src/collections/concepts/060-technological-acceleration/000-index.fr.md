# Technological acceleration

The compounding speed at which a society moves from **discovery → infrastructure → deployment**. Distinct from “shipping more tickets”.

Tied to the [[kardashev-scale|Kardashev Scale]] when the bottleneck is energy and coordination, not marketing cadence.
