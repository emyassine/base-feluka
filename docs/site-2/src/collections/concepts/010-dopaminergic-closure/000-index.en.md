# Dopaminergic closure

When a unit of work is **actually finished**, reward-prediction circuits can settle: the gap between “expected done” and “done” collapses. That settling is what we call dopaminergic closure here — a practical label, not a clinical diagnosis.

See also [[task-completion|task completion]].
