# How to manage cookies and browser storage

The privacy control lets you review browser storage used by this website and choose whether to allow optional storage. It applies only to the site address shown in the control. Your choice does not apply to other websites, even if they are operated by Numerimondes.

## Open the control

Select **Manage cookies** at the bottom of the page. On your first visit, the control opens automatically. You can reopen it at any time to change your choices.

The **Choices** tab describes each storage purpose. The **Browser storage** tab lists items this page can detect, with a short description and a removal action where removal is available. Browser security can hide some items; for example, page scripts cannot inspect cookies marked `HttpOnly`.

## Necessary storage

Necessary storage is always enabled and shown with a checked, disabled control. It supports features you directly use on this site:

- your light, dark, or system theme;
- the currency used to display prices;
- your marketplace shortlist and reviews on this device;
- remembering your optional storage choices.

These functions do not perform tracking. The page language follows its URL and is not saved as a language preference.

## Optional storage

You can allow or reject offline catalogue storage and other optional browser storage. Choose **Save choices** to apply the switches as shown. **Reject optional** turns off both optional choices and removes the optional data this site can identify. **Allow optional storage** enables both optional choices.

You can also remove a detected item individually from the **Browser storage** tab. Removing data may reset a site feature or cause a catalogue to download again. Necessary items cannot be removed from this control because the site relies on them for its stated functions.

## Change your choice later

Open **Manage cookies**, change the optional switches, and save again. The site stores this choice in a first-party consent cookie for up to 180 days. Clearing site data in your browser also clears the saved choice, so the control may ask again on a later visit.
