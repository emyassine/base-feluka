## Why this is a separate service from Infrastructure

Infrastructure keeps existing systems running. Automation builds something new but small: a workflow that replaces a specific piece of manual work. The two get confused because both can involve no-code tools — but the intent is different. Infrastructure asks "is production healthy?" Automation asks "why is a person still doing this by hand?"

## Pricing method: value, not hours

We price automation work against the time and cost it saves you, not a day rate. A workflow that removes hours of manual re-keying every week is worth a fixed fee tied to that outcome — not to how many hours we spent building it.

| Formula | Scope | Typical basis |
|---|---|---|
| **Single workflow** | One process automated end to end (e.g. quote generation) | Fixed price, sized to time/cost saved |
| **Department rollout** | Several linked workflows across one function (sales, HR, or finance) | Fixed price per milestone |
| **Operator training** | No-code / AI upskilling for your internal team | Fixed price per session or programme |

Payment stays milestone-based, as on every Numerimondes service: never fully upfront, never a single invoice at the end.

## Where it hosts

Automation workflows run on infrastructure you control — on-prem, a private cloud, or [Numerimondes Cloud](/services/cloud) if you choose to host with us. No perpetual platform tax for core automation: ownership first, convenience second.
