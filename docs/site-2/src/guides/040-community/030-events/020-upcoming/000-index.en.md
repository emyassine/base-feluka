# Upcoming events

Pre-register on Numerimondes. 

- Presence is checked at the start and end of each session; 
- participants receive a **verifiable online attestation**.

Need an account? [Log in](https://www.numerimondes.com/app/login) · [Create account](https://www.numerimondes.com/app/register) · [My events (portal)](https://www.numerimondes.com/app/my-events)


<br>



## How it works

1. Open an event and register (free for convention formats).
2. Show up and get checked in / out by the Numerimondes team.
3. Receive a link to verify your attestation online.
