## Services vs solutions

| | **Services** | **Solutions** |
|---|---|---|
| What | One unit offer | Several services in one package |
| Example | [Audit](/services/audit) alone | [Modernization](/solutions/modernization) = Audit + the work that follows |
| Writing | Full redaction on the service page | Composition + links — no copy-paste of unit pages |
| Where | [/services](/services) | This section |
