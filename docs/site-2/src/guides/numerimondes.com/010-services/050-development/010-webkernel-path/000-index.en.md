## What Webkernel is, in this context

Webkernel is an open-source foundation built for digital sovereignty: the idea that a company should own its tools instead of depending permanently on a foreign SaaS stack it can never fully control. It was created by Yassine El Moumen before Numerimondes existed as a business, and it remains the technical backbone behind several of our own products.

When we scope a Development engagement, Webkernel is one path we can propose — not the only one, and never forced.

## What "sovereign" means in practice

- **Source leverage** — you are not waiting on a vendor roadmap to ship a feature you need today.
- **Data locality** — your data lives where you decide to host it, including fully air-gapped if required.
- **No forced SaaS rent** — the core application does not carry a recurring per-seat licence to a third party.
- **Your roadmap, not someone else's toggle** — a vendor cannot deprecate a feature you depend on out from under you.

## How it fits with the rest of Numerimondes

- An [Audit](/services/audit) can identify where a self-hosted foundation would remove ongoing SaaS cost — Webkernel is often the concrete answer to that finding.
- Once a Webkernel-based system ships, running it long-term is [Infrastructure](/services/infrastructure) work: hosting, monitoring, and operator training. It can also run on [Numerimondes Cloud](/services/cloud) if you choose managed hosting instead of your own hardware.
- Webkernel itself has its own [product page](/numerimondes/docs/oss/webkernel) with technical documentation, separate from this services context.
