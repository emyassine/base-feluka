## The idea

Most firms sell modernisation as a vague transformation story. We sell a **path of real bricks**.

The first brick is already a closed pack: the [Audit service](/services/audit) — Level 1 technology inventory or Level 2 value-chain diagnostic, report, conference, roadmap. That writing stays on the Audit page. This solution **starts there** and continues only if you choose to.

You can stop after the audit. You can enter later if you already know what to build. The package is composition, not lock-in.

## How we price the package

Each phase can still be priced as its unit service. For the **Modernization** package we work one of two ways:

| Mode | What you get | Typical basis |
|---|---|---|
| **Phased programme** | Signed sequence (e.g. Audit → Consulting → first build/automation milestone) | Fixed price per phase, agreed before that phase starts |
| **Full path quote** | One commercial envelope after Audit + decision | Order of magnitude after diagnosis; closed milestones for delivery |

Payment stays milestone-based. No 100% upfront. An audit alone never commits you to the rest of the package.

For Audit’s own packages (Level 1 / Level 2, conference, payment split), see the [Audit service page](/services/audit) — that redaction is not duplicated here.
