# À propos de Numerimondes

Numerimondes SARL AU est une entreprise indépendante de logiciels. Elle
possède et accompagne Feluqa, une plateforme logicielle en cours de
développement.

Pour toute question sur l’entreprise ou ses produits, écrivez à
[contact@numerimondes.com](mailto:contact@numerimondes.com) ou visitez
[numerimondes.com](https://numerimondes.com).
