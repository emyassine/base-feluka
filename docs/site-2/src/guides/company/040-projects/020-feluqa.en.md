## What it is

Feluqa is Numerimondes’ application platform project, a Rust-based framework. It aims to support efficient application development across different environments, with emphasis on control, performance and maintainable systems.

## Directions under exploration

- Applications spanning backend, desktop, mobile and connected environments.
- Reusable components and consistent development conventions.
- Efficient runtimes and deployment approaches for demanding use cases.
- Engineering patterns for operational software and systems integration.

These are design objectives, not available features or completed production deployments.

## Status

In development. Documentation, examples, supported platforms, licensing and release plans will be published when ready.

## Commissioned work

Custom software and Rust engineering missions are available independently of Feluqa. Whether to use the framework is decided per project, on technical requirements and maturity.
