# Feluqa

**Coming soon · In development**

## Engineering across platforms and environments.

Feluqa is a Rust-based application framework initiative being explored and developed at Numerimondes. Its intended direction is to support efficient application development across different environments, with an emphasis on control, performance and maintainable systems.

### Areas under exploration

- Applications spanning backend, desktop, mobile and connected environments.
- Reusable components and consistent development conventions.
- Efficient runtimes and deployment approaches appropriate to demanding use cases.
- Engineering patterns for operational software and systems integration.

These are **design objectives and research directions**, not claims of available product features or completed production deployments.

## Status

Feluqa remains in development. Public documentation, technical examples, supported platforms, licensing and release plans will be published when ready.

## Commissioned work

Numerimondes can discuss custom software and Rust engineering missions independently of Feluqa's eventual release. Framework adoption is assessed against each project's technical requirements and maturity.
