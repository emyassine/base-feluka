# Platform support

The current supported development path is the web profile on the Rust host platform used by the checkout. SQLite and PostgreSQL are the database dialects implemented today.

The architecture defines server, web, desktop, mobile, game and embedded profiles. Target shells, air-gapped packaging, standalone workstation apps and mobile apps are not all implemented. A target is supported only after its build and runtime checks pass.

See [Feluqa at a glance](../01.welcome/01.overview.en.md) and [the current work](../999-roadmap/01.index.en.md).
