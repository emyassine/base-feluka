# Add routes and organize your app

Declare routes with the site, panel or module that owns them. The application route file composes route providers and applies global middleware; it should not own every product URL.

Keep domain models, migrations, permissions, resources and services together. Use Rust modules for source organization. A Rust `mod` is not an installable Feluqa module.

See [Routing](../03.core-concepts/05.routing.en.md) and [the module layout reference](../technical/02.architecture/06.platform-module-layout.en.md).
