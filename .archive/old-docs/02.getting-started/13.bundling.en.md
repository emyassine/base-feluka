# Build and bundle your app

Cargo compiles Rust code. The Feluqa view compiler validates `.view.rs` templates and generates Rust into Cargo's `OUT_DIR`. Production apps serve compiled views; they do not interpret template files at request time.

Public web assets are served from `public/`. Keep dashboard data and user input out of the Rust compilation path.

Run `feluqa build` for a release build. Generated apps outside the checkout and a universal cross-platform bundler are still roadmap work.
