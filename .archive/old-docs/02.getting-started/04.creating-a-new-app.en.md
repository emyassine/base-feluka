# Create a new app

The Feluqa CLI scaffolds a web app with configuration, compiled views, a database setup and statically linked modules.

```sh
feluqa new bookstore --profile web
```

From a source checkout, run the CLI with Cargo:

```sh
cargo run -p feluqa-cli -- new bookstore --profile web
```

The default scaffold location depends on where you run the command. The CLI does not overwrite an existing directory. Generated apps outside this repository need a compatible Feluqa release in the private registry; that path is not qualified yet.

Run `feluqa dev` from the generated app directory. See the [CLI guide](../04.guides/02.tools.en.md) if the command is not available on your PATH.
