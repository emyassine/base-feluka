# Create UI with RSX

Feluqa does not currently ship an RSX authoring syntax. The current UI authoring path is HTML-like `.view.rs` templates that compile into Rust.

```html
<main>
  <h1>Welcome</h1>
  <p>This is a compiled Feluqa view.</p>
</main>
```

Use escaped `{{ expression }}` output for dynamic text. Use the documented typed component syntax only for components registered by the consuming app. Do not treat this HTML example as an RSX example.

The headless UI architecture describes the target component model. See [Building User Interfaces](../03.core-concepts/02.building-user-interfaces.en.md) and [the `.view.rs` language reference](../technical/05.reference/05.view-language.en.md).
