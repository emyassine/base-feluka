# Fetch data

Fetch protected data through a Feluqa route or service. Validate request parameters, apply authorization on the server, and return only fields the caller may access.

The browser Live client does not yet reconcile shared state end to end. For a reliable current workflow, use the server route and the app's normal page response.

See [Fullstack](../03.core-concepts/04.fullstack.en.md) and [Routing](../03.core-concepts/05.routing.en.md).
