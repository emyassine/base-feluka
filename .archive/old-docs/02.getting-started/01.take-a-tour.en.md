# Take a tour of Feluqa

A Feluqa app is a Rust product built from routes, services, data models, compiled views and framework modules. The CLI scaffolds the app and runs its development server.

```text
App source
  ├── routes and services
  ├── modules and migrations
  ├── .view.rs templates
  └── public assets
        ↓
Feluqa CLI → Cargo build → web app
```

Start with the [getting-started overview](02.overview.en.md), then create an app and follow the pages in order. The [core concepts](../03.core-concepts/01.overview.en.md) explain how the framework fits together.
