# Set up your tools

Feluqa builds from the root Cargo workspace. Install the Rust toolchain specified by `rust-toolchain.toml`, then run commands from the repository root.

## Required tools

- Rust and Cargo
- A C toolchain and platform libraries required by the crates you build
- Git

## Check the CLI

From the repository root, run:

```sh
cargo run -p feluqa-cli -- help
```

To build the CLI binaries from source, use `./build.sh`. Target-specific cross builds also need the target linker and SDK.

The architecture document defines the settled target layout. The current workspace is still being moved toward it; see [Project Structure](../06.beyond/03.project-structure.en.md).
