# Technical reference archive

The single entry point for Feluqa documentation is the [main documentation index](../00.index.en.md). This archive contains deeper architecture, implementation, policy, research and migration material linked from that index. It is not a separate set of user guides. See the [documentation writing guidelines](DOCS_GUIDELINES.md) when editing these references.

Use the framework guides for the developer workflow. Follow links into this archive only when you need the detailed technical contract behind a guide. The [active roadmap](../999-roadmap/01.index.en.md) owns unfinished work; the [work-package lookup](roadmap/08.crates-change-plan.en.md) maps earlier crate task IDs.

English is normative. French plans retain detailed historical evidence and are
marked for synchronization. The [migration ledger](06.governance-and-policy/04.documentation-migration.en.md)
accounts for every source, including proposals, questions and working notes.
