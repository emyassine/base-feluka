# Feluqa product direction

Feluqa is a proprietary Rust framework for building web products and installable business modules. One framework and namespace serve multiple runtime profiles; each profile keeps the dependencies and behavior its target needs.

## Product rules

- Feluqa is the host platform. Developers build business capabilities as Feluqa modules.
- The server and web profile come first.
- A module owns its business rules. Products compose modules without forking those rules.
- The product must support hosted use and local installations. A local host serves nearby browser or native clients without Internet access.
- The platform includes shared services, a generic panel system and a built-in System Panel as the product target.
- UI meaning and state are shared where practical. Each target uses an appropriate renderer or native shell.
- Modules declare capabilities. Installation, signing, licensing and rollback are enforced by the platform when that lifecycle is delivered.
- Commands and contracts should be usable by both people and coding agents.

## What is available now

The checkout has a web application foundation, CLI, compiled `.view.rs` templates, SQLite and PostgreSQL support, authentication and authorization foundations, and static module composition. Desktop and mobile shells, dynamic installation, offline synchronization and qualified deployment are not complete.

Use the [developer guide](../../00.index.en.md) for the framework workflow and its [roadmap](../../999-roadmap/01.index.en.md) for active work. The [Monorepo Architecture](../02.architecture/01.monorepo-architecture.en.md) defines the technical structure.
