# Expose authorized agent tools

Track: **AN-04 / CR-13 — service**. Status: **incomplete**.

The agent service and MCP/API hosting boundary are not implemented.

Prerequisites: [Complete deterministic application discovery](../04.application-tooling/15.application-scanner.en.md), [Add scoped agent principals](23.agent-principals.en.md).

## Work

1. Select the protocol/version and hosting boundary for one representative tool consumer.
2. Route validated, bounded tool requests through the same authorized services as other clients.
3. Exercise malformed input, denied capabilities, cancellation and untrusted content as data.

## Acceptance

A real consumer completes an allowed operation and is denied an unauthorized one. Add a service crate only with its first useful contract and integration.
