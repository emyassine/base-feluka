# Deliver shared business dashboards

Track: **CR-10**. Status: **incomplete**.

Integrated BI is a selected requirement, not a delivered catalogue.

Prerequisites: [Complete the shared UI component catalogue](05.ui-components.en.md), [Complete Core and generic resource actions](../03.platform-services/06.core-resource-actions.en.md).

## Work

1. Add versioned chart/series schemas and reusable dashboard components with filters, tables and export.
2. Keep aggregation bounded and authorized in services; include tenant, permissions, parameters and freshness in cache keys.
3. Exercise grant-change invalidation, large data, light/dark themes, keyboard alternatives and live refresh.

## Acceptance

A representative dashboard passes tenant-denial and accessibility checks; changing filters or data never compiles Rust.
