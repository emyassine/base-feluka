# Complete ownership of the UI runtime

Track: **F10 / CR-01 — runtime**. Status: **incomplete**.

Existing Feluqa UI packages do not establish complete runtime ownership or support for every target.

## Work

1. Audit runtime source, dependencies, namespaces, provenance and feature gates before replacing or internalizing remaining external implementation.
2. Preserve web SSR/hydration and the no_std schema boundary through a representative consumer.
3. Record supported compiler/profile lanes and keep unverified native outputs marked as targets.

## Acceptance

The maintained runtime surface, third-party notices and supported build lanes are documented and verified; a component-source copy alone is insufficient.
