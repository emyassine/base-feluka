# Integrate target renderers and native shells

Track: **F9 / CR-11 — native surfaces**. Status: **incomplete**.

Native shells, bridges and their target-specific build lanes remain incomplete.

Prerequisites: [Complete ownership of the UI runtime](../02.ui-and-panels/12.ui-runtime.en.md), [Run one module on hosted web and a local workstation](13.local-workstation.en.md), [Verify dependencies, MSRV and target profiles](../06.build-and-dependencies/22.dependency-target-validation.en.md).

## Work

1. Implement one useful bridge/renderer and shell consumer at a time using the selected architecture boundaries.
2. Keep native projects outside Cargo and share business rules and semantic UI contracts across targets.
3. Verify lifecycle, input, accessibility, bundled assets and capability fallbacks on each claimed target.

## Acceptance

Each supported target has a working product consumer and recorded build/runtime evidence; unbuilt targets remain explicit.
