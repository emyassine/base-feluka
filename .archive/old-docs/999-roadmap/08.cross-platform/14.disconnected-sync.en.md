# Define and implement disconnected-device synchronization

Track: **F9 / CR-11 — synchronization**. Status: **incomplete**.

Offline writes, reconnect semantics, conflict handling and detailed security protocols remain open.

Prerequisites: [Run one module on hosted web and a local workstation](13.local-workstation.en.md).

## Work

1. Define which data devices can read/write while disconnected and choose synchronization and conflict behavior per data type.
2. Specify enrollment, revocation, transport protection, key custody and authorization changes during disconnection.
3. Implement a bounded workflow covering concurrent edits, reconnect, lost devices and restore from backup.

## Acceptance

Tests demonstrate documented conflict outcomes, tenant isolation, audit continuity and recovery. LAN access alone does not satisfy this task.
