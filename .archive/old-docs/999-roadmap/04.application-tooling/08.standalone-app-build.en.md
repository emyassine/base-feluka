# Build generated applications outside the checkout

Track: **F6 — application delivery**. Status: **incomplete**.

The local scaffold and watcher exist; standalone generated-app builds remain unverified.

## Work

1. Generate an application into an independent directory with the approved dependency and registry configuration.
2. Remove accidental checkout-relative assumptions from generated manifests, build discovery, views and assets.
3. Build and run a second independent site and document the supported scaffold-to-build workflow.

## Acceptance

A generated product builds outside the repository using documented prerequisites, with no copied framework-owned views or assets.
