# Deliver declarative panel and resource APIs

Track: **F12 / CR-03**. Status: **incomplete**.

The selected attribute-driven APIs are not yet a complete replacement for manual product declarations.

Prerequisites: [Complete deterministic application discovery](15.application-scanner.en.md), [Complete the shared UI component catalogue](../02.ui-and-panels/05.ui-components.en.md), [Complete Core and generic resource actions](../03.platform-services/06.core-resource-actions.en.md).

## Work

1. Implement main, panel, resource, page, permissions, roles, config and gate contracts through the Feluqa facade.
2. Generate routes, navigation, typed permissions and secure write gates with compile-fail diagnostics.
3. Migrate a representative product and remove manual declarations only after equivalent behavior passes.

## Acceptance

The product derives runtime configuration from its source declarations, with denial tests and no duplicate maintained registries.
