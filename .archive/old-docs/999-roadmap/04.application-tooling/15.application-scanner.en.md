# Complete deterministic application discovery

Track: **F11 / CR-02 / AN-02**. Status: **incomplete**.

Basic discovery, context and inventory checks exist. Runtime generation and complete attribute validation remain open.

## Work

3. Consume the inventory in a real product; verify stable ordering, unchanged output on no-op builds and correct invalidation.
