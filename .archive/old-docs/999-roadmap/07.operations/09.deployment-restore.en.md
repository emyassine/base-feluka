# Qualify deployment and restore

Track: **F6 — operations / AN-06**. Status: **incomplete**.

Production deployment, restore and enterprise release qualification are incomplete.

Prerequisites: [Build generated applications outside the checkout](../04.application-tooling/08.standalone-app-build.en.md), [Complete Core and generic resource actions](../03.platform-services/06.core-resource-actions.en.md).

## Work

1. Define staged artifact delivery, secret injection, readiness checks, graceful shutdown, observability and resource limits.
2. Exercise database migration compatibility, failed activation, rollback and backup/restore using a representative product.
3. Document operational runbooks and retain results for each applicable release gate; code rollback must not be treated as data rollback.

## Acceptance

A recorded deployment and restore drill recovers the product and its data. Module-based delivery also requires the installable-module task.
