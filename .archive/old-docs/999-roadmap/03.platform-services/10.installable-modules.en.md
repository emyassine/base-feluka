# Deliver the installable module lifecycle

Track: **F7 / CR-07**. Status: **incomplete**.

Static registration, ordering and rollback contracts exist. Application wiring and installable artifacts remain pending.

Planning estimate: 12–20 days. Re-estimate before implementation; this is not a release date.

## Work

1. Wire the static lifecycle into a representative application before adding dynamic artifacts.
2. Implement the selected WASM Component Model boundary with compatibility, signatures, licensing and explicit capability checks.
3. Cover staging, domain activation, upgrade failure, recovery, disable and uninstall with explicit migration and data-retention behavior.

## Acceptance

An authorized operator installs, activates, upgrades and recovers a real module; invalid signatures, incompatible artifacts and undeclared capabilities are denied.
