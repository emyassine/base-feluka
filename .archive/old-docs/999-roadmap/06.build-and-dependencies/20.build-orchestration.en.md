# Deliver measured build orchestration

Track: **CR-09**. Status: **incomplete**.

The development watcher exists. Generated-crate orchestration and resource-budgeted build control remain planned.

## Work

1. Record cold, warm, no-op, page-edit and shared-contract build timings, peak memory and workstation responsiveness.
2. Remove unnecessary generation and invalidation; prototype partitioning only for a measured bottleneck.
3. Implement deterministic pre-build orchestration, atomic/concurrent cache handling and configurable CPU/memory budgets; verify failures leave the previous HTTP process available.

## Acceptance

Before/after evidence includes representative small and large products, interrupted/concurrent generation, cache separation and runtime correctness. Readiness-checked handover requires separate startup and migration evidence.
