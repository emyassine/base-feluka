# Deliver versioned CLI machine output

Track: **AN-01 / CR-08 — output**. Status: **incomplete**.

Universal JSON output is not delivered.

Prerequisites: [Complete Console interaction and execution](17.console-interaction.en.md).

## Work

1. Define versioned output schemas, stable error/exit codes and stderr-only progress.
2. Audit and implement the contract for each advertised command while preserving human-readable output.
3. Add contract cases for success, denial, cancellation, invalid input and piped execution.

## Acceptance

Each command advertised as supporting machine output passes the schema and exit-code contract; unsupported commands remain explicit.
