# Complete Console interaction and execution

Track: **CR-08 — Console**. Status: **incomplete**.

Registry, profiles, help and basic prompts exist. Async execution, richer interaction and supervision remain incomplete.

## Work

1. Keep synchronous commands runtime-neutral and add an opt-in asynchronous adapter with cancellation and shutdown behavior.
2. Complete search/autocomplete, form navigation, progress widgets, shell completion and process supervision against the Console contract.
3. Exercise TTY and piped input, non-interactive failures and terminal resize behavior.

## Acceptance

The CLI consumes the shared engine and tests cover cancellation, terminal and non-interactive behavior without requiring a server runtime for synchronous commands.
