# Complete the compiled view language

Track: **F1 / CR-04**. Status: **incomplete**.

The build-time compiler and application consumer exist. Full language and diagnostic acceptance remains open.

Planning estimate: 10–16 days. Re-estimate before implementation; this is not a release date.

Prerequisites: [Connect the shared view conformance corpus](02.view-conformance.en.md).

## Work

1. Close the compiler gaps identified by the shared corpus, following the existing syntax contract.
2. Exercise declared roots, namespaces, include/layout cycles, typed props and slots through a representative application build.
3. Add rendering, error and compile-fail coverage in debug and release modes, including SafeUrl and prohibited JavaScript/CSS interpolation.

## Acceptance

The representative consumer renders correctly and invalid templates fail with actionable source locations in both profiles.
