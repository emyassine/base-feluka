# Port the remaining first-party Webkernel views

Track: **F0/F1 — consumer port**. Status: **incomplete**.

The syntax inventory provides historical source evidence. Porting the first-party site still needs application-level rendering checks.

Prerequisite: [Complete the compiled view language](03.view-compiler.en.md).

## Work

1. Port the error-page shell and compare output at representative widths.
2. Add a typed asset-manifest component for the site consumer.
3. Move locale, navigation, documentation lookup and asset URL logic into Rust services; compose the welcome view from smaller compiled components.
4. Introduce sanitized Markdown or script-safe JSON only when a consumer needs it, with dedicated encoding and denial coverage.

## Acceptance

The product builds and renders its error, asset and welcome views with typed data and validated URLs. PHP expressions and implicit discovery are replaced by explicit Rust contracts. Shared component work stays in the [UI catalogue task](../02.ui-and-panels/05.ui-components.en.md).
