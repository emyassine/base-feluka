# Deliver global IDE support commands

Track: **F2 — IDE commands**. Status: **incomplete**.

The support:ide command family is planned, independently of parser and editor validation.

Planning estimate: 3–6 days for global commands, Tree-sitter export and Zed; separate adapters need their own estimate. Re-estimate before implementation; this is not a release date.

Prerequisites: [Complete Tree-sitter and Zed validation](04.editor-validation.en.md).

## Work

1. Implement context-independent list, status, check, highlight, install and remove operations for supported adapters.
2. Keep checking read-only by default and restrict installation/removal to Feluqa-managed user-level files.
3. Use approved grammar/extension sources and validate each advertised editor’s native integration format.

## Acceptance

Commands work from app, workspace and unrelated directories; install/remove preserves unrelated settings. Generic Tree-sitter export includes source, queries, fixtures and instructions.
