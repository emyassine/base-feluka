# Connect the shared view conformance corpus

Track: **F0 / CR-04**. Status: **incomplete**.

The compiler and Tree-sitter have separate tests. A shared language corpus is still missing.

Planning estimate: 3–5 days. Re-estimate before implementation; this is not a release date.

## Work

1. Inventory the directives and component behavior required by first-party consumers against the view language contract.
2. Create shared positive and negative fixtures with explicit compiler and editor expectations; keep grammar dependencies out of the server.
3. Run both consumers against the corpus and record intentional differences, diagnostics and source locations.

## Acceptance

Both test suites consume the same fixtures, including escaping, URL attributes, nested Rust syntax and malformed input.
